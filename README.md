# 排便记录小工具 🚽

一个极简的桌面小工具,用于记录个人排便情况,数据自动保存到本地 Excel 文件,方便长期追踪身体状况,也可用于就医时给医生参考。

## 功能特点

- 🖥️ 单文件运行,无需安装数据库,双击即用
- 📊 数据直接写入 Excel(.xlsx),可随时用 Excel/WPS/Numbers 打开查看
- 📋 记录内容基于 [布里斯托大便分类法](https://zh.wikipedia.org/wiki/布里斯托大便分类法)(Bristol Stool Scale),科学、标准
- 🔒 数据完全存储在本地,不联网、不上传,隐私安全
- 🪶 界面轻量,几秒钟完成一次记录

## 记录字段

| 字段 | 说明 |
|---|---|
| 日期 / 时间 | 自动填入当前时间,可手动修改 |
| Bristol 分型 | 1-7 型,对应粪便性状(1=便秘 …… 7=腹泻) |
| 顺畅度 | 顺畅 / 一般 / 费力 |
| 颜色 | 正常 / 偏浅 / 偏深 / 带血 / 其他 |
| 备注 | 自由填写,可留空 |

## 环境依赖

- Python 3.8 及以上
- 依赖库:

\`\`\`bash
pip install openpyxl
\`\`\`

(tkinter 为 Python 自带库,一般无需单独安装;若是 Linux 系统提示缺失,可运行 `sudo apt install python3-tk`)

## 使用方法

1. 克隆本仓库或直接下载 `main.py`
2. 安装依赖: `pip install openpyxl`
3. 运行程序:

\`\`\`bash
python main.py
\`\`\`

4. 首次运行会在脚本同目录下自动创建 `排便记录.xlsx` 文件
5. 之后每次记录都会追加写入该文件,不会覆盖历史数据
6. 点击界面上的"打开Excel"按钮可随时查看完整记录

## 数据存储说明

所有数据仅保存在你本地电脑上的 `排便记录.xlsx` 文件中,程序不会联网、不会上传任何信息。如需备份或迁移,直接复制这个 Excel 文件即可。
